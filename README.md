# Globle Country Abbreviations

A Tampermonkey userscript that adds common country abbreviations and
country codes to [Globle](https://globle-game.com/).

## Examples

| Input | Globle receives |
|---|---|
| `dprk` | North Korea |
| `rok` | South Korea |
| `aus` | Australia |
| `arg` | Argentina |
| `nz` | New Zealand |
| `uk` | United Kingdom |
| `uae` | United Arab Emirates |
| `drc` | Dem. Rep. Congo |

The script runs entirely in the browser and does not send guesses
anywhere.
